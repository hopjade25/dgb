# dgb 차트 포맷 v2 (BMS 스타일 평문)

UTF-8 텍스트. `;` 뒤는 주석. MUSIC SELECT의 [불러오기] 또는 OPTION의 "차트 파일 불러오기…"로 `.txt`/`.dgb` 를 읽습니다 (불러온 곡은 "불러온 곡" 폴더에 추가). 내장 곡은 "And Revive The Melody"(ARTM) 하나뿐(`dgb/index.html` 안의 `<script id="artm-BASIC|MEDIUM|HARD|SPECIAL">`). 데모·X·랜덤 생성곡은 v3.5에서 삭제(차트 파일은 charts/에 남음).
기준판: REFLEC BEAT VOLZZA 2. 悠久のリフレシア 요소(빅뱅·스위치 롱·KEEP)는 없음.

## 헤더
| 키 | 의미 | 기본 |
|---|---|---|
| `#TITLE` `#ARTIST` | 표시용 | |
| `#DIFF` | BASIC / MEDIUM / HARD / SPECIAL (VOLZZA 2 명칭) | |
| `#LEVEL` | 1–12 (VOLZZA의 10+ 분할 이후 체계) | |
| `#BPM n` | 시작 BPM (내장 드럼 합성에도 사용) | 120 |
| `#LEAD s` | 0박 시작 전 대기(초) | 2.0 |
| `#FALL s` | 기본 낙하시간(출현→판정, 초). BPM과 독립 — 원작도 보면별 속도가 BPM과 무관 | 1.7 |
| `#SEED n` | 출발 x·반사 여부 시드 | 없음 |
| `#PATH RANDOM\|FIXED` | RANDOM=매 플레이 경로 재추첨(원작처럼), FIXED=#SEED로 고정. 생략 시 #SEED가 있으면 FIXED | RANDOM |
| `#BPMxx v` | BPM 정의 (`BP` 채널에서 사용) | |
| `#SPDxx v` | 낙하시간 배율 정의 (1.5=느림, 0.7=빠름) — `SP` 채널에서 사용 | |

### 궤적
- 빨강: 상단 랜덤 x 출발 → 목표 중심으로 직선, 35% 확률로 옆벽 1회 반사.
- **초록(TOP): 벽 반사 없음** — 출발점→버튼 중심 직선(원작 TOP처럼). 출발 x: 좌 버튼=왼쪽 절반(28–180), 우=오른쪽 절반(180–332), 중앙=150–210(±80 → 100–260). 놓치면 같은 방향으로 계속 날아가 화면 밖으로.
- 체인(빨강·초록 모두)은 첫 노트와 같은 경로 공유.

낙하시간은 차트(#FALL·SP 채널)로만 정해집니다(하이스피드 옵션 폐지).

## 데이터 줄
`#MMM:CH:데이터` — MMM=마디(1마디=4박), CH=채널, 데이터=마디를 균등 분할한 슬롯(길이 자유: 8=8분, 16=16분, 12=셋잇단, 32=32분…). 같은 마디·채널 줄을 여러 번 써도 됩니다(해상도가 다른 줄을 섞을 수 있음).

### 채널
| CH | 목표 |
|---|---|
| `R1`…`R6` | 빨강 착지점 x = 360·(k−0.5)/6 → 30…330, 판정 밴드(화면 하단) |
| `GL` `GM` `GR` | 초록 버튼(TOP 대응): 좌·중앙·우. y = 판정선 − 0.20×필드높이 (VOLZZA 실측) |
| `BP` | BPM 변경 — 2자 ID |
| `SP` | 낙하속도 배율 변경 — 2자 ID |
| `BB` | (v1 호환) 빅뱅 폐지 → 경고 후 R3/R4 통상으로 변환 |

### 노트 토큰
| 토큰 | 의미 | 초록 채널 |
|---|---|---|
| `0` | 없음 | |
| `1` | 통상 오브젝트 | ✅ |
| `2` `4` | 통상 (v1의 블랙; JR 폐지로 골드/블랙 구분 없음) | ✅ |
| `C` `D` | 체인 — 같은 채널 직전 노트와 같은 경로·간격으로 연결(縦連/연타) | ✅ |
| ~~`V` `W`~~ | **폐지**(버티컬 오브젝트 제거) — 경고 후 통상으로 변환 | |
| `L` … `E` | 롱 시작 … 롱 끝 | ❌→통상(E 무시) |
| `K` | 체인 끝 롱 (롱은 체인의 끝에만) | ❌→체인 |
| `F` | **플릭 오브젝트** — 판정 밴드에서 터치다운 후 280ms 안에 22px 이상 스와이프(방향 무관). 판정 타이밍 = 터치다운 시각. 탭만으로는 맞지 않음 | ❌→통상 |

초록(TOP) 채널은 **통상만** 허용합니다(사용자 규칙). 특수 토큰은 경고와 함께 변환됩니다.

### 판정·점수 (VOLZZA 2 기준)
- JUST ±50ms / GREAT ±100ms / GOOD ±150ms (🛠 dgb 값; 원작 수치 비공개). 점수 +3/+2/+1, MISS −3.
- 롱: 시작 판정을 끝까지 유지하면 확정. 끝 1/4박 전부터는 떼도 성공. 도중 이탈은 MISS + 남은 길이 비례 −1~−3, 놓침 −6.
- AR = (3·JUST + 2·GREAT + GOOD) / (3·N), 0.1% 단위 버림. 랭크 AAA+ 95 · AAA 90 · AA 80 · A 70 · B 60 · C. 클리어 AR ≥ 70%.
- 보너스: 미스카운트 보너스 FC +50 / 1미스 +25 / 2미스 +10.

### 패턴 작성법 (용어 → 표기)
| 용어 | 작성 |
|---|---|
| 체인/縦連/연타 | `#005:R4:1C0C0C00` |
| 트릴(체인 2개 교대) | `#016:R2:1010C0C0` + `#016:R5:0101010C` |
| 계단(階段) | 인접 레인을 한 칸씩: R1→R2→R3… |
| 데님 | 레인 체인과 TOP 체인을 교대: `R3:10C0C0C0` + `GM:01010C0C` 비슷하게 |
| 즈레(ズレ, 미세 어긋남) | 32분 이상 해상도로 1슬롯 어긋나게: `R1:1000…` + `R4:0100…` (32칸). 같은 시각이 아니므로 동시치기 테두리 없음 |
| 롱잡(LO絡み/軸) | 한 레인 `L…E` 동안 다른 레인에 단타 |
| 동시치기 | 같은 슬롯에 서로 다른 채널 |
| 소프란 | `SP` / `BP` 채널 |

### 예시
```
#TITLE Example
#DIFF HARD
#LEVEL 9
#BPM 140
#BPM01 175
#SPD01 1.6
#001:R1:10001000        ; 4분 통상 2개
#001:GM:00100000        ; 중앙 버튼
#002:R3:1C0C0000        ; 체인 3개
#002:R5:L000E000        ; 롱 2박
#002:R1:00F00000        ; 플릭
#003:SP:01              ; 여기서부터 느리게
#004:BP:01              ; BPM 175
#004:R2:1C0C0C0C        ; 체인 연타
#005:R1:10000000000000000000000000000000
#005:R4:01000000000000000000000000000000   ; 즈레(1/32 박 뒤)
```

### 초록(TOP) 사이드 목표 (v3.2)
초록 노트는 벽의 영향을 받지 않는다(통과). 좌/우 버튼 노트의 중심은 판정 시각에 반원 버튼 중심(x=0 / x=W, y=BTN_Y)에 정확히 도착한다. 중앙은 (W/2, BTN_Y). 경로는 항상 직선, 반사·클램프 없음, 화면 밖으로 벗어난 부분은 캔버스에서 잘려 그려진다. 스폰 x: 좌 60~200, 우 160~300, 중앙 100~260.

## v3.3 추가
### 마디 길이 `ML` (변박)
`#MMM:ML:x` — 그 마디 길이를 4/4 대비 배율로 지정(BMS 02 채널과 같음). 5/4=`1.25`, 3/4=`0.75`, 7/8=`0.875`, 15/16=`0.9375`, 4/8=`0.5`, 1/4=`0.25`, 2/4=`0.5`. 분수 `5/4` 표기도 허용. 이후 마디 시작 박이 누적으로 밀립니다. 데이터 슬롯은 그 마디 길이를 균등 분할.
### 셋잇단 격자
슬롯 수는 자유이므로 셋잇단은 12(8분 셋잇단, 4/4), 24(16분 셋잇단), 48(32분 셋잇단)… 로 씁니다. 내장 곡 ARTM은 1박=48슬롯 격자(16분·셋잇단·32분·64분 공용)를 최대공약수로 압축해 저장합니다.
### BP 채널 박 위치
`#MMM:BP:00XX…` 처럼 마디 안 위치에 BPM 변경을 넣을 수 있음(ARTM 89마디: 198 → 2박째 180).
### 트릴
시간차로 교대하는 **두 체인**(서로 다른 빨강 레인)을 쓰면 트릴이 됩니다:
```
#016:R2:1000C000C000C000   ; 체인 A (정박)
#016:R5:00100C000C000C00   ; 체인 B (엇박) — 실제로는 같은 격자에서 교대
```
파서는 시간이 겹치며 교대하는 두 체인 쌍을 트릴로 인식해 **경로가 서로 교차하지 않게**(왼쪽 레인 체인은 자기 레인보다 왼쪽에서, 오른쪽 체인은 오른쪽에서 출발, 반사 없음) 다시 배치합니다. 체인 길이 4+4가 표준(원작 '4+4·2+2 쌍'), 2+3+3+…+2의 '渡りトリル'(겹쳐 이어지는 체인)도 같은 방식으로 작성 가능.
### #MUSIC
`#MUSIC ARTM` / `#MUSIC MIDI:A`…`MIDI:F` — 내장 합성 반주 지정(내장 곡 전용). 없으면 기본 킥/햇.
### 카운트다운
곡 시작은 3-2-1 카운트다운(1초 간격). LEAD가 3초 미만이면 3초로 늘립니다.
